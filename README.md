# CABINSA Landing

Versión empresarial inspirada en Evergreen Siteworks, adaptada a CABINSA SRL.

## Archivos

```txt
cabinsa-landing/
├── index.html
├── css/styles.css
├── js/app.js
└── assets/cabinsa-logo.png
```

## WhatsApp

En `js/app.js`, cambiar:

```js
const WHATSAPP_NUMBER = "";
```

por el número real en formato internacional, sin `+`, espacios ni guiones.
